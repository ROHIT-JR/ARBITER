# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and critique ideas rather than people. Harassment or discriminatory behaviour will not be tolerated.

To report unacceptable behaviour, open a confidential issue with the maintainers, or contact the repository owner through GitHub. Maintainers will review every report and respond as the Covenant's enforcement guidelines describe.
